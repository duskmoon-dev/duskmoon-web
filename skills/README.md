# Skills for released Duskmoon Web packages

Use these skills in an application that installs Duskmoon Web packages from npm, Hex, or crates.io. Copy the selected skill directory with its `SKILL.md` and any `references/` so its local links keep working. Choose package versions from the [published Web releases](https://github.com/duskmoon-dev/duskmoon-web/releases) and pin matching versions for packages used together.

| Skill | Covers |
| --- | --- |
| [duskmoon-dev-core](duskmoon-dev-core/SKILL.md) | Tailwind v4, Core themes, component CSS and native interactions |
| [duskmoon-dev-css-art](duskmoon-dev-css-art/SKILL.md) | CSS Art styles, markup and custom properties |
| [duskmoon-elements](duskmoon-elements/SKILL.md) | Element registration, attributes, events, slots and parts |
| [duskmoon-art-elements](duskmoon-art-elements/SKILL.md) | CSS Art as custom elements |
| [duskmoon-components](duskmoon-components/SKILL.md) | Native React and Next.js components |
| [duskmoon-art-components](duskmoon-art-components/SKILL.md) | React wrappers for CSS Art |
| [duskmoon-phoenix](duskmoon-phoenix/SKILL.md) | `duskmoon_phoenix`, native HEEx and optional integrations |
| [duskmoon-code-engine](duskmoon-code-engine/SKILL.md) | TypeScript editor and Elements adapter |
| [duskmoon-yew](duskmoon-yew/SKILL.md) | Yew components, Core CSS, Trunk and the Rust editor Worker |
