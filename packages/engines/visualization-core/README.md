# Duskmoon Visualization Core

Use `layoutXY` or `layoutHeatmap` to turn a typed chart input into domains,
normalized plot geometry, resolved colors and diagnostics under the
[Duskmoon Visualization Contract](https://github.com/duskmoon-dev/duskmoon-web/tree/main/specs/visualization/v1).
The package can run in Node.js without React or a DOM.
