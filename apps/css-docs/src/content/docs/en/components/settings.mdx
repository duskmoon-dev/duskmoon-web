## Configuration types

| Setting | Native HTML |
| --- | --- |
| Navigation | A link, optional current value, and decorative chevron |
| Switch or checkbox | A labeled checkbox with switch or checkbox styling |
| Text, range, select, and multiline text | A labeled text input, range input, select, or textarea |
| One choice or multiple choices | A labeled group of radios or checkboxes |
| Read-only information | A value, badge, or description |
| Custom action | A labeled button or other control in the trailing slot |

The group surface and inset separators come from `.settings-section-items`. Use `.settings-row-stacked` for a control that needs its own line. Associate help text with its control, choice group, or section using `aria-describedby`.
