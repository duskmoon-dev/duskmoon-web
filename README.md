# Duskmoon Web

Duskmoon Web delivers Core/Tailwind, CSS Art, Custom Elements, and native React, Phoenix, and Yew components. Each package is independently installable. The public Web packages publish together at the version in [VERSION](VERSION).

| Use | Packages | Versions |
| --- | --- | --- |
| Tailwind and CSS | `@duskmoon-dev/core`, optional `@duskmoon-dev/css-art` | [![@duskmoon-dev/core version on npm](https://img.shields.io/npm/v/@duskmoon-dev/core/rc?label=%40duskmoon-dev%2Fcore)](https://registry.npmjs.org/%40duskmoon-dev%2Fcore/rc) [![@duskmoon-dev/css-art version on npm](https://img.shields.io/npm/v/@duskmoon-dev/css-art/rc?label=%40duskmoon-dev%2Fcss-art)](https://registry.npmjs.org/%40duskmoon-dev%2Fcss-art/rc) |
| Custom Elements | `@duskmoon-dev/elements`, `@duskmoon-dev/art-elements`, or individual `@duskmoon-dev/el-*` packages | [![@duskmoon-dev/elements version on npm](https://img.shields.io/npm/v/@duskmoon-dev/elements/rc?label=%40duskmoon-dev%2Felements)](https://registry.npmjs.org/%40duskmoon-dev%2Felements/rc) [![@duskmoon-dev/el-base version on npm](https://img.shields.io/npm/v/@duskmoon-dev/el-base/rc?label=%40duskmoon-dev%2Fel-base)](https://registry.npmjs.org/%40duskmoon-dev%2Fel-base/rc) [![@duskmoon-dev/art-elements version on npm](https://img.shields.io/npm/v/@duskmoon-dev/art-elements/rc?label=%40duskmoon-dev%2Fart-elements)](https://registry.npmjs.org/%40duskmoon-dev%2Fart-elements/rc) |

The Phoenix library defaults to native HEEx and lightweight hooks. LiveView can mount the native React Form and Chat through explicit feature imports. The React packages use Core styling and React peers. The Elements registrations are standalone. The Hologram compiler and runtime are released through [Duskmoon Bundler](https://github.com/duskmoon-dev/duskmoon-bundler).

## Development

```sh
bun install --frozen-lockfile
bun run build:packages
bun run test:packages
bun run verify:react-boundary
```

`packages/` contains the JS libraries. `apps/` contains the JS demos, docs sites, and starters. The `phoenix/` Mix workspace contains the Phoenix library and Storybook, which includes Hologram examples.
The `yew/` Cargo workspace contains both Rust crates and the separate private Trunk demo.
